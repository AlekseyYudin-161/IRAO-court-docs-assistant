# Примеры судебных актов для передачи юристу

В наборе 11 учебных обезличенных PDF на 43 страницах и перечень из 10 фраз-маркеров. Файл "Фразы и примеры.csv" сохраняет соответствие фраз и примеров из исходного перечня. Для фразы "оставить… без рассмотрения" приведены два акта.

Набор дополняет основные материалы судебной задачи примерами отбора актов для дополнительной работы юриста. При анализе учитывайте контекст фразы и резолютивную часть документа.

ФИО заменены обозначениями "Лицо NN", названия сторон - "Орг. NN". Адреса сторон, идентификаторы, номера дел и договоров, суммы и даты, относящиеся к обстоятельствам дел, удалены или замаскированы. Часть дат и номеров в правовых ссылках также скрыта. Электронные подписи и персональные данные в служебных полях удалены. Названия судов и общедоступные адреса судов сохранены.

Сохранены количество, порядок и размеры страниц, расположение исходного текста и текстовый слой. На месте удалённых полей стоят условные обозначения. Эти примеры предназначены для проверки отбора актов по содержанию. Для проверки извлечения сумм, дат и реквизитов используйте основной учебный набор судебной задачи.

Файлы "Акт_01.pdf" - "Акт_11.pdf" можно открывать по отдельности. Контрольные суммы файлов приведены в manifest.json.
