# Расхождения разметки и наших значений

Общий файл junior ML и BI/DA. Разметку в `labels/` не правим и правила под id не подгоняем
(орги 01.10: эталон размечен нейросетью и местами неточен).

Класс **а** — разметка не совпадает с текстом документа: оставляем наше значение, фиксируем цитату.
Класс **б** — наше значение неверно: заводим задачу на правило (кому — в «решение»).

Файл лежит в docs/, а не в work/: work/ целиком в .gitignore. `src/eval/report.py` читает эту таблицу: ячейки класса «а» помечаются в `report.md` и считаются отдельно.
Формат строки строгий: первый столбец — имя файла (`ocr_014` или путь), второй — имя столбца как в шаблоне.
