Критерии жюри: репрезентативность материалов (Р), качество и новизна реализации (К), бизнес-ориентированность (Б).
Числа в [скобках] — заполнить после финального прогона из `out/metrics.md`.

| № | Слайд | Что на слайде | Критерий |
|---|---|---|---|
| 1 | Помощник по судебным документам | Одна фраза: «Документ из суда или ФССП → таблица реквизитов → решение, нужен ли юрист, → письмо с основанием и сроком». Команда AAATeam, ссылка на сервис, QR | — |
| 2 | Задача и для кого | Сотрудник по взысканию дебиторской задолженности вручную переносит реквизиты из приказов, ИЛ и постановлений ФССП; часть — сканы. Цена ошибки: пропущенный 10-дневный срок на обжалование | Б |
| 3 | Вход → выход | Слева: 4 типа документов + судебные акты (PDF, сканы, XML). Справа: ocr.csv / xml.csv по шаблонам заказчика, реестр, письмо. Скрин вкладки «Документ» | Р |
| 4 | Как устроено | `docs/architecture_v2.4.png`. Три подписи: XML — без LLM; электронный PDF — якоря; скан — OCR + локальная LLM только для пустых полей, значение принимается только с цитатой из текста | К |
| 5 | Каждое значение доказуемо | Скрин таблицы полей: значение, уверенность, метод, цитата; серые — не извлечено с причиной. «Пустое лучше неверного» | К |
| 6 | Письмо юристу | Скрин письма fssp_012: L1, отказ в возбуждении ИП, норма, срок до …, цитата, два вложения. Уровни L1/L2/L3 + канал ручной проверки. Правила — в одной таблице `rules/codes.py`, юрист заказчика правит их без программиста | Б |
| 7 | Судебные акты | 10 фраз заказчика ищутся только в резолютивной части; срок обжалования — из текста акта. [11/11] актов распознаны верно, ложных срабатываний на приказах/ИЛ/ФССП — [0] | Р, Б |
