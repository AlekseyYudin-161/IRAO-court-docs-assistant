Команда: AAATeam

# Задача – Помощник по судебным документам (OCR и извлечение данных)
Одна строка: что делает и для кого. Версия: `v0.1-dev`.

## Быстрый старт
5 команд: clone → setup → run-examples → где смотреть результат → как открыть UI.
Требования к железу: macOS/Linux, Python 3.11, Tesseract rus, Ollama (опционально, `--no-llm` без него).

## Что умеет / что не умеет
Две короткие колонки. Ограничения честно — это оцениваемый раздел.

## Данные
Состав набора (из README организаторов, 2 строки), раскладка в `data/`, `labels/` как эталон, hold-out 13 файлов.

## Как это работает
Схема конвейера (картинка `docs/architecture.png`), 6 строк текстом: XML-ветка, PDF-ветка, правила, экспорт.

## Результаты
Таблица per-column EM (dev / hold-out), doc-all-columns, время на документ. Заполняется в четверг после прогона.
Ссылка на `out/report.md` — «ожидаемое vs извлечённое» и разбор ошибок.

## Письмо юристу
Правила маршрутизации: код → основание → срок. Пример письма.

## Структура репозитория
Дерево папок в одну строку на каждую, кто владелец.
